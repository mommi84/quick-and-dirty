# quick-and-dirty
Quick &amp; dirty code for projects that don't even deserve their own repository.

## Projects

* [👑 royal-genealogy-tree](royal-genealogy-tree) — climb a person's full
  ancestry (via Wikidata or a FamilySearch GEDCOM) and watch it fan out into the
  royal houses of Europe, enriched with Wikipedia bios.
* [☕ london-cafe-density](london-cafe-density) — a rigorously unscientific map of
  London ranked by cafés per 100 people.
* [🍿 film-selector](film-selector) — surfaces well-rated unseen films from a
  Google Doc watchlist.
* [🍽️ excusestoeat](excusestoeat) — an ExcusesToEat leaderboard.
